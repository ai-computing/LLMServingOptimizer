  ```bash
  export PATH="$HOME/.local/bin:$PATH"
  ```

## 3. 스윕 실행 스크립트 (`script/`)

### 신규 파일: `script/run_a6000_4_sweep.sh` (87줄)

- 11개 유효 설정에 대해 **smoke(10 req)** → **full(100 req)** 2단계 실행
- 각 실행 결과를 `output/a6000_4_sweep/{smoke,full}/<label>.{csv,log}`에 저장
- 실패 시 즉시 중단 (`set -e` + `Simulation results` 마커 확인)
- 실행 방법: `bash script/run_a6000_4_sweep.sh [smoke|full|both]`

### 신규 파일: `script/build_a6000_4_report.py` (199줄)

- `output/a6000_4_sweep/full/` 하위 로그·CSV를 파싱하여 `A6000_4_REPORT.md` 생성
- 추출 지표: Total latency, Request throughput, Prompt/Gen/Total TP, Mean/Median/P99 TTFT·TPOT·ITL, NPU 메모리 사용률

## 8. 웹 UI 구현 (`webapp/`)

### 백엔드 Python 모듈 (3,393줄)

| 파일 | 역할 | 줄수 |
|---|---|---|
| `config.py` | 경로 상수, SIM_ENV, HW_DEFAULTS, MAX_CONCURRENT | 40 |
| `hardware_catalog.py` | `llm_profile/perf_models/` 스캔 → (HW, Model, TP set) | 76 |
| `enumerate.py` | 시나리오 → 유효한 모든 ConfigSpec 목록 생성 | 381 |
| `cluster_builder.py` | ConfigSpec → 시뮬레이터용 cluster JSON | 134 |
| `parser.py` | 로그 regex + CSV → metrics dict (ns→ms 변환) | 171 |
| `runner.py` | asyncio 스윕 오케스트레이터 (병렬 실행, SSE, 취소) | 420 |
| `plots.py` | Plotly JSON 생성 (바 차트, 파레토, 선형, CDF) | 310 |
| `app.py` | FastAPI 앱, 13개 라우트 | 554 |

### 프론트엔드 (391줄 HTML + 393줄 CSS + 598줄 JS)

| 파일 | 역할 |
|---|---|
| `templates/base.html` | 공통 레이아웃, Plotly.js CDN 로드 |
| `templates/index.html` | 시나리오 빌더 (하드웨어/모델 선택, 축 체크박스, 열거 미리보기) |
| `templates/progress.html` | SSE 기반 실시간 진행 상황 테이블 |
| `templates/results.html` | Plotly 차트 4종 (바, 파레토, 선형, CDF) + 다운로드 |
| `templates/sweeps_list.html` | 과거 스윕 이력 |
| `static/app.css` | 커스텀 CSS (프레임워크 없음) |
| `static/app.js` | 바닐라 JS — 폼 처리, SSE 클라이언트, Plotly 초기화 |

### 주요 기능

- **하드웨어 카탈로그 자동 감지**: 4개 하드웨어, 5개 모델, TP 옵션 자동 감지
- **이기종 하드웨어 지원**: 인스턴스별 하드웨어 설정 (예: H100 prefill + A6000 decode)
- **크로스 하드웨어 비교**: 다수 시나리오를 동시에 정의하고 결과 오버레이
- **소프트 캡**: 20개 초과 시 체크박스 UI로 실행 대상 선택
- **병렬 실행**: `asyncio.Semaphore(K)` 기반 최대 K개 동시 실행 (K = min(4, cpu//2))
- **실시간 모니터링**: Server-Sent Events로 진행 상황 스트리밍
- **취소 기능**: SIGTERM으로 진행 중인 모든 서브프로세스 종료
- **재연결 안전성**: `status.json` 원자적 쓰기로 브라우저 새로고침 후 상태 복원
